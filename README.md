## Tech Stack
- **Framework:** Next.js 16 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS (v4) with custom luxury gold gradients and glassmorphism design tokens
- **Animations:** Framer Motion, HTML5 Canvas Golden Dust Particle Engine, Canvas Confetti
- **Typography:** Cormorant Garamond, Cinzel, Outfit (Google Fonts)
- **Icons:** Lucide React & Custom Brand Vector SVGs
- **Image Optimization:** `next/image` with responsive blur and priority loading

---

## Getting Started

### 1. Install Dependencies (already installed)
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
npm run start
```

## Implemented Website Sections
1. **Cinematic Hero (100vh):** Deep black canvas with floating gold particles, slow Ken Burns camera drift on royal heritage wedding portrait, luxury gold shimmer heading, and instant action CTAs.
2. **Brand Introduction:** Split-screen layout displaying *"YOUR MOMENTS. OUR LENS. FOREVER."*, studio stats counter, and layered photographic collage.
3. **3D Golden Aperture Experience:** Interactive camera aperture with f-stop depth-of-field slider (f/1.2 to f/16), mechanical blade rotation, and audio-visual shutter trigger with gold confetti.
4. **Bespoke Services:** 6 image cards with gold gradient overlays for Wedding Photography, Modeling, Pre-Wedding, Post-Wedding, Droneography, and Video Editing with detailed modal drawers.
5. **Film Raw vs Graded Truth Slider:** Interactive before/after comparison revealing flat camera LOG profiles blooming into our 12-bit champagne gold grade.
6. **Featured Portfolio & Lightbox:** Filterable masonry gallery with categories (*All, Weddings, Pre-Weddings, Events, Modeling, Cinematography, Celebrations*) and a full-screen keyboard-navigable Lightbox.
7. **Why Choose Us:** 4 feature pillars showcasing master team, cinema-grade hardware, signature color science, and 100% satisfaction.
8. **Cinematic Brand Statement:** Full-screen twilight drone palace backdrop with magnetic golden CTA.
9. **Customer Testimonials:** Luxury quote carousel with star ratings and clear review template indicators.
10. **Contact & Booking Section:** Full verified business details, direct `tel:` and `wa.me` links, Google Maps destination card, and a booking form that compiles inquiries directly to WhatsApp.
11. **Footer:** Scalable vector SVG brand logo, tagline, quick navigation, studio hours, and back-to-top button.
12. **Interactive Polish:** Custom golden ring cursor, top scroll progress line, session-aware welcome popup, and floating WhatsApp CTA.
